在 PyCharm 中运行 `uvicorn main:app --reload` 时，发现有时无法通过 Ctrl+C 快捷键终止进程。这种情况下可以切换到终端，用下面几个命令来结束占用端口的进程：

```
netstat -ano | findstr :<端口号>    # 查看目标端口使用情况
tasklist /fi "PID eq <PID>"    # 查看目标端口是什么程序占用
taskkill /PID <PID> /F    # 终止该进程
```

但如果遇到下面这种情况：

```
PS C:\Users\周毅> netstat -ano | findstr :8000
  TCP    127.0.0.1:8000         0.0.0.0:0              LISTENING       7984
PS C:\Users\周毅> tasklist /fi "PID eq 7984"
信息: 没有运行的任务匹配指定标准。
PS C:\Users\周毅> taskkill /PID 7984 /F
错误: 没有找到进程 "7984"。
```

就只能重启电脑了，目前我还没有找到更好的解决方案。建议在 powershell 中 cd 到目标项目之后执行 uvicorn main:app --reload 命令，不要在pycharm的终端中执行，可以尽量避免pycharm终端终止进程权限不够的问题。
