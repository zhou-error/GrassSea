# 🌊 GrassSea 教学文件 — 从零到一构建 AI 多智能体协作平台

> ⚠️ **范围说明（项目定位：个人使用）**
>
> 本套教程覆盖 12 个阶段，其中**集群部署（K3s）、CI/CD 流水线、可观测性（Jaeger / Prometheus / Grafana）**
> 属于通用工程知识，**当前项目不包含这部分能力**：相关流水线与部署清单已从仓库移除，
> 对应容器配置也已从 `docker-compose.yml` 移除。这些章节可作为学习资料，但无需在本项目中落地。
>
> 另外，与代码实现保持一致的两处修正：
> 1. 对话服务端口是 **8001**（旧稿曾写 8011）；
> 2. `alembic.ini` 位于**项目根目录**（不在 `shared/models/`），且连接串由 `env.py` 从 `.env` 读取。

> 本教学文件以 **GrassSea（白草沧智）** 项目为蓝本，手把手教你从 Python 基础进阶开始，
> 逐步构建一个完整的 **FastAPI 微服务 + React 前端 + AI 多智能体 + RAG 知识库** 全栈项目。

## 🎯 学习目标

完成全部教学文件后，你将能够：

1. **独立搭建 Python 全栈项目**：从 pyproject.toml 配置到 Docker 容器化部署
2. **设计多数据库架构**：PostgreSQL + MongoDB + Redis + Milvus 选型与协同
3. **开发 FastAPI 微服务**：异步 API、中间件、WebSocket、SSE 流式输出
4. **构建 RAG 知识库引擎**：文档预处理 → 向量化 → 混合检索 → 答案生成
5. **实现多智能体系统**：意图识别 → DAG 任务规划 → 状态机 → 多 Agent 协同
6. **编写 React 前端**：TypeScript + Zustand 状态管理 + Ant Design 组件库
7. **部署到生产环境**：Docker 容器化 + CI/CD 流水线 + K3s 集群

## 🚀 如何使用

### 方式一：按阶段顺序学习（推荐）

从 `00-学前准备/` 开始，按编号顺序逐文件学习。每个文件末尾有练习任务，建议完成后再进入下一章。

### 方式二：按需跳跃学习

如果你已具备某项技能，可跳过对应阶段。例如：
- 熟悉 Python 异步 → 跳过 00-01
- 用过 SQLAlchemy → 跳过 00-03、02-02~02-05
- 写过 React → 跳过 09-01~09-04

### 方式三：跟着项目做

打开 GrassSea 项目源码，对照教学文件中的「项目代码精讲」部分，边看边改代码实验。

## ⚠️ 注意事项

1. **一定要动手实践**：只看不写代码是学不会的。每个文件的「手把手实践」部分请务必手动敲一遍。
2. **遇到报错不要慌**：每个文件的第 5 节「常见问题与排错」收录了新手最常遇到的错误。
3. **视频是辅助**：视频链接帮助理解概念，但核心内容都在文字和代码中。
4. **不要跳阶段**：后面的阶段依赖前面的知识，跳阶段大概率会卡住。
5. **善用 AI 助手**：遇到不懂的地方，可以复制代码和错误信息询问 AI。
