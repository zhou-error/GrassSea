## 概念讲解

### GrassSea 的三栏布局

```
+--------------------------------------------------------------+
|  TopNav (高度 52px, 磨砂玻璃, 浮动)                           |
|  [Logo 白草沧智]    GrassSea AI          [在线状态]            |
+--------------------------------------------------------------+
|  Sidebar   |  主内容区 (Routes 切换)                | DAGPanel|
|  (88px)   |                                       | (280px) |
|            |  /chat      -> ChatPage              | (仅对话 |
|  项目      |  /knowledge -> KnowledgePage          |  页显示)|
|            |  /tasks     -> TaskCenterPage         |         |
|  知识库    |  /settings  -> SettingsPage           |         |
|            |                                       |         |
|  智能体    |                                       |         |
|            |                                       |         |
|  ...       |                                       |         |
|  配置      |                                       |         |
+--------------------------------------------------------------+
|  ShimmerBar (高度 3px, 渐变色流光动画)                        |
+--------------------------------------------------------------+
```

四个结构层：
1. **TopNav** — 顶部固定导航，品牌标识
2. **Sidebar** — 左侧功能导航，路由切换
3. **主内容区** — 中间（flex: 1），根据路由渲染不同页面
4. **ShimmerBar** — 底部装饰性进度条，品牌动画

### 为什么用这个布局？

```
传统管理后台:  TopNav + 侧边菜单 + 内容区  (Ant Design Pro 风格)
GrassSea:     TopNav + 图标侧栏 + 双栏内容

差异:
- 侧栏用图标代替文字（更简洁，留出更多空间给内容）
- 右侧固定面板（DAGPanel）用于辅助信息展示
- 聚焦"对话"为核心交互模式
```

## 项目代码精讲

### 1. App.tsx — 应用根布局

**文件位置**: `frontend/src/App.tsx`

```typescript
import React from 'react';
import { Routes, Route, Navigate } from 'react-router-dom';
import TopNav from './components/TopNav';
import Sidebar from './components/Sidebar';
import ShimmerBar from './components/ShimmerBar';
import ChatPage from './pages/Chat';
import KnowledgePage from './pages/KnowledgeBase';
import TaskCenterPage from './pages/TaskCenter';
import SettingsPage from './pages/Settings';

const App: React.FC = () => (
  <div style={{
    display: 'flex',
    flexDirection: 'column',
    height: '100vh',
    overflow: 'hidden',
  }}>
```

**逐段解析**：

1. `height: '100vh'` — 占满视口高度。`100vh` = 视口高度的 100%。
2. `overflow: 'hidden'` — 禁止整个页面滚动。滚动由各子区域（消息列表、文件列表）内部处理。
3. `flexDirection: 'column'` — 纵向排列（TopNav 在上，内容区在中，ShimmerBar 在下）。

```typescript
    {/* 顶部悬浮导航 */}
    <TopNav />

    {/* 主体三栏布局 */}
    <div style={{
      display: 'flex',
      flex: 1,                  // 占据剩余空间
      overflow: 'hidden',       // 禁止溢出
      position: 'relative',
      zIndex: 1,                // 在 SVG 背景之上
    }}>
      <Sidebar />

      {/* 中间 + 右侧内容区 */}
      <div style={{
        flex: 1,
        display: 'flex',
        overflow: 'hidden',
        padding: '16px 16px 6px 8px',
        gap: 12,                // 子元素间距 12px
      }}>
        <Routes>
          <Route path="/chat" element={<ChatPage />} />
          <Route path="/knowledge" element={<KnowledgePage />} />
          <Route path="/tasks" element={<TaskCenterPage />} />
          <Route path="/settings" element={<SettingsPage />} />
          <Route path="*" element={<Navigate to="/chat" replace />} />
        </Routes>
      </div>
    </div>

    <ShimmerBar />
  </div>
);
```

**代码精讲**：

1. `flex: 1` — 让内容区占据 TopNav 和 ShimmerBar 之外的所有空间（TopNav 和 ShimmerBar 高度固定）。

2. `zIndex: 1` — 确保布局在 SVG 波浪背景（`z-index: 0`）之上。没有这个设置，背景会遮挡交互元素。

3. `gap: 12` — Flexbox 的 `gap` 属性，设置子元素之间的间距。比手动加 `margin` 更简洁。

4. `<Route path="*" element={<Navigate to="/chat" replace />} />` — 通配路由，所有未知路径重定向到 `/chat`。`replace` 表示替换浏览历史而非追加，这样用户按"后退"不会回到 404 页面。

### 2. TopNav — 顶部导航栏

**文件位置**: `frontend/src/components/TopNav.tsx`

```typescript
const TopNav: React.FC = () => (
  <nav
    className="glass"
    style={{
      height: 52,
      display: 'flex',
      alignItems: 'center',
      justifyContent: 'space-between',
      padding: '0 24px',
      zIndex: 100,
      flexShrink: 0,
      margin: '8px 12px 0 12px',
      borderRadius: 'var(--radius-lg)',
      position: 'relative',
    }}
  >
```

**代码精讲**：

- `className="glass"` — 应用磨砂玻璃效果（来自 `index.css` 的 `.glass` 类）
- `margin: '8px 12px 0 12px'` — 导航栏四周有间距，不与视口边缘紧贴。这是"浮动导航"的设计——导航栏似乎悬浮在页面之上
- `zIndex: 100` — 最高层级，确保导航栏始终在内容之上
- `flexShrink: 0` — 高度固定 52px，不会被压缩

```typescript
    {/* 左侧 Logo */}
    <div style={{ display: 'flex', alignItems: 'center', gap: 10, width: 200 }}>
      <svg width="28" height="28" viewBox="0 0 28 28" fill="none">
        <defs>
          <linearGradient id="logoGrad" x1="0" y1="0" x2="28" y2="28">
            <stop offset="0%" stopColor="#C1D5C0" />
            <stop offset="100%" stopColor="#B5D6E0" />
          </linearGradient>
        </defs>
        <path d="M4 22 Q8 10 14 6 Q20 10 24 22"
              stroke="url(#logoGrad)" strokeWidth="1.8"
              fill="none" strokeLinecap="round" />
        <path d="M6 18 Q10 12 14 10 Q18 12 22 18"
              stroke="url(#logoGrad)" strokeWidth="1.2"
              fill="none" strokeLinecap="round" opacity="0.6" />
      </svg>
      <span>白草沧智</span>
    </div>
```

**SVG Logo 精讲**：

Logo 由两条二次贝塞尔曲线组成：
- `M4 22 Q8 10 14 6 Q20 10 24 22` — 外弧（起点 (4,22)，控制点 (8,10) 和 (20,10)，终点 (24,22)）
- `M6 18 Q10 12 14 10 Q18 12 22 18` — 内弧（更小的曲线，透明度 0.6）

两条弧线共同形成一个"船体截面"的抽象形状，呼应"船舶与海洋工程"领域的项目主题。

`<linearGradient>` 定义了鼠尾草绿到冰川蓝的渐变，通过 `id="logoGrad"` 和 `stroke="url(#logoGrad)"` 引用。注意 `id` 在 SVG 中是全局的——如果页面有多个 SVG 使用相同 `id`，会产生冲突。

```typescript
    {/* 居中品牌 */}
    <span style={{
      fontSize: 15,
      fontWeight: 700,         // Bold
      letterSpacing: '0.04em',
      color: 'var(--text-primary)',
      position: 'absolute',
      left: '50%',
      transform: 'translateX(-50%)',
    }}>
      GrassSea AI
    </span>
```

居中文字使用 `position: absolute + left: 50% + translateX(-50%)` 实现精确的水平居中。这种组合是 CSS 中居中元素的经典写法。

```typescript
    {/* 右侧状态 */}
    <div style={{ display: 'flex', alignItems: 'center', gap: 8,
                  width: 200, justifyContent: 'flex-end' }}>
      <span style={{
        width: 7, height: 7, borderRadius: '50%',
        background: 'var(--status-green)',
        display: 'inline-block',
        animation: 'dotPulse 2s ease-in-out infinite',
      }} />
      <span style={{ fontSize: 11, color: 'var(--text-muted' }}>
        在线
      </span>
    </div>
```

状态指示灯是一个 7x7 的绿色圆点，使用了 index.css 中定义的 `dotPulse` 动画——以 2 秒为周期呼吸闪烁。这给用户一个"系统正在运行"的持续提示。

左右两侧各占 `width: 200`，中间文字绝对居中，形成严格的左-中-右三段式布局。

### 3. Sidebar — 侧边栏

**文件位置**: `frontend/src/components/Sidebar.tsx`

#### 导航项定义

```typescript
interface NavItem {
  key: string;
  icon: React.ReactNode;
  label: string;
}

const navItems: NavItem[] = [
  { key: '/chat',      label: '项目',   icon: <svg>...</svg> },
  { key: '/knowledge', label: '知识库', icon: <svg>...</svg> },
  { key: '/tasks',     label: '智能体', icon: <svg>...</svg> },
];
```

每个导航项包含：
- `key` — 路由路径，用于匹配和跳转
- `icon` — SVG 内联图标（不使用 Ant Design Icons，而是自定义手绘 SVG）
- `label` — 中文标签

#### 路由联动

```typescript
const Sidebar: React.FC = () => {
  const navigate = useNavigate();
  const location = useLocation();

  // 判断是否当前活跃路由
  const active = location.pathname.startsWith(item.key);

  // 点击跳转
  onClick={() => navigate(item.key)}
```

**路由切换机制**：

1. `useNavigate()` — React Router 提供的导航函数，`navigate('/chat')` 等于 `<a href="/chat">`
2. `useLocation()` — 获取当前路由信息（路径、查询参数等）
3. `location.pathname.startsWith(item.key)` — 用 `startsWith` 匹配（而非 `===`），这样 `/chat/123` 也属于 "项目" 导航

#### 活跃状态视觉指示

```typescript
style={{
  width: 56, height: 56,
  background: active ? 'rgba(193,213,192,0.22)' : 'transparent',
  color: active ? '#3D5A45' : 'var(--text-secondary)',
  fontWeight: active ? 600 : 400,
}}

{/* 活跃指示条 */}
{active && (
  <span style={{
    position: 'absolute',
    left: 8, top: '50%',
    transform: 'translateY(-50%)',
    width: 2.5, height: 16,
    borderRadius: 4,
    background: 'var(--accent-sage)',
  }} />
)}
```

活跃状态有三个视觉信号：
1. **背景色变化** — 淡绿色背景（22% 不透明度）
2. **文字颜色加粗** — 从灰色 `#666` 变为深绿 `#3D5A45`，字重从 400 变为 600
3. **左侧指示条** — 一个 2.5x16px 的竖条，垂直居中于按钮左侧

这三种信号叠加，确保用户在任何状态下都能迅速识别当前所在页面。

#### SVG 手绘图标

```typescript
icon: (
  <svg width="18" height="18" viewBox="0 0 18 18" fill="none">
    <rect x="2" y="2" width="14" height="14" rx="3"
          stroke="currentColor" strokeWidth="1.3" />
    <path d="M6 7h6M6 10h4" stroke="currentColor"
          strokeWidth="1.2" strokeLinecap="round" />
  </svg>
),
```

**为什么用手绘 SVG 而不用 Ant Design Icons？**

用 `stroke="currentColor"` 可以让图标颜色跟随父元素的 `color` 属性。这意味着活跃状态的文字颜色变化会自动应用到图标上，不需要为图标单独设置颜色。

相比之下，Ant Design Icons 的颜色需要显式传入 `style={{ color: ... }}`。

#### 磨砂玻璃 + 侧光晕

```typescript
<aside className="glass" style={{ width: 88, ... }}>
  {/* 侧面光晕 */}
  <div style={{
    position: 'absolute',
    top: '20%', right: -20,
    width: 40, height: '60%',
    background: 'radial-gradient(ellipse at center,
      rgba(181,214,224,0.12) 0%, transparent 70%)',
    pointerEvents: 'none',
  }} />
```

侧光晕是一个椭圆形径向渐变（`radial-gradient`），从冰川蓝色（12% 不透明度）渐变到完全透明。它模拟了"光线从侧面照射玻璃"的物理效果，让磨砂玻璃更有立体感。

`pointerEvents: 'none'` 确保光晕不拦截任何鼠标事件。

### 4. ShimmerBar — 底部流光条

**文件位置**: `frontend/src/components/ShimmerBar.tsx`

```typescript
const ShimmerBar: React.FC = () => (
  <div style={{
    height: 3,
    flexShrink: 0,
    margin: '0 12px 8px 12px',
    borderRadius: 6,
    background: 'linear-gradient(90deg,
      var(--accent-glacier), var(--accent-sage), var(--accent-glacier))',
    backgroundSize: '200% 100%',
    animation: 'shimmer 4s ease-in-out infinite',
    zIndex: 10,
    opacity: 0.8,
  }} />
);
```

**流光动画原理**：

```
background: linear-gradient(90deg, 冰川蓝, 鼠尾草绿, 冰川蓝)
                                    |_________|_________|
                                     200% 总宽度

backgroundSize: '200% 100%'  -->  背景宽度是元素的2倍

animation: shimmer 4s ease-in-out infinite
    @keyframes shimmer {
      0%   { background-position: -200% 0; }
      100% { background-position: 200% 0; }
    }
```

动画效果：渐变色从左滑到右，形成"流光"效果。`backgroundSize: '200%'` 是关键——它让渐变只有一半可见，另一半在视口外。通过移动 `background-position`，可见部分从冰川蓝渐变到鼠尾草绿再回到冰川蓝。

```
0秒:  [████████░░░░░░░░]   可见区域是冰川蓝
1秒:  [░░████████░░░░░░]   可见区域是绿蓝过渡
2秒:  [░░░░████████░░░░]   可见区域是鼠尾草绿
3秒:  [░░░░░░████████░░]   可见区域是绿蓝过渡
4秒:  [████████░░░░░░░░]   循环回到冰川蓝
```

### 实践3: 实现 TopNav 的滚动隐藏效果

当页面内容向下滚动时，TopNav 自动隐藏（节省垂直空间）：

```typescript
const [visible, setVisible] = useState(true);

useEffect(() => {
  let lastScrollY = window.scrollY;
  const handler = () => {
    const currentScrollY = window.scrollY;
    setVisible(currentScrollY < lastScrollY || currentScrollY < 50);
    lastScrollY = currentScrollY;
  };
  window.addEventListener('scroll', handler);
  return () => window.removeEventListener('scroll', handler);
}, []);

// 在 TopNav 样式中
style={{
  transform: visible ? 'translateY(0)' : 'translateY(-100%)',
  transition: 'transform 0.3s ease-in-out',
}}
```

## 常见问题与排错

### Q1: Sidebar 点击导航后页面没切换

**检查步骤**:
1. 确认 `App.tsx` 中已配置对应路由
2. 确认 `navigate(item.key)` 的路径与 Route 的 `path` 完全匹配
3. 确认组件文件存在且正确 export default

### Q2: TopNav 的 SVG Logo 在 React 中渲染异常

**常见原因**: SVG 属性使用了 JSX 不支持的命名方式。
**注意**: JSX 中 `stroke-width` 应写为 `strokeWidth`（驼峰），`stroke-linecap` 写为 `strokeLinecap`。

### Q3: `z-index` 层级混乱

GrassSea 的 z-index 层级：
```
z-index: 0   -> SVG 波浪背景 (body::before)
z-index: 1   -> 主内容区
z-index: 10  -> Sidebar, ShimmerBar
z-index: 100 -> TopNav (最高层)
```

如果某个元素被意外遮挡，检查它的 z-index 是否在正确的层级区间。

### Q4: 页面在移动端布局错乱

**原因**: 三栏布局使用了固定像素宽度（Sidebar 88px, DAGPanel 280px）。
**当前状态**: GrassSea 前端没有实现响应式设计，仅在桌面端（>= 1024px）使用。如果需要移动端适配，需要使用 `@media` 查询将三栏改为单栏堆叠布局。
