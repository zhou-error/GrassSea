## 概念讲解

### 什么是设计系统？

设计系统是一套统一的视觉语言规则，包括：

```
设计系统
  |
  +-- 颜色系统 (Color Palette)
  |     - 背景色、文字色、强调色、状态色
  |
  +-- 间距系统 (Spacing)
  |     - 统一的 margin / padding 比例
  |
  +-- 圆角系统 (Border Radius)
  |     - 按钮圆角、卡片圆角、浮层圆角
  |
  +-- 阴影系统 (Shadow)
  |     - 不同层级的阴影深度
  |
  +-- 字体系统 (Typography)
        - 字号层级、行高、字重、字体家族
```

有了设计系统，团队中每个人写出的组件看起来是"一家人"，而不是各写各的风格。

### Quiet Luxury（静奢极简）设计风格

GrassSea 面向船舶工程专业人士，设计风格追求"克制的高级感"而非花哨：

```
传统工程软件界面: 高饱和蓝、粗边框、表格泛滥
Quiet Luxury:      低饱和色、模糊玻璃、极简留白
```

核心特征是"少即是多"：
- 颜色数量少，降低认知负担
- 大量留白，突出内容本身
- 微妙的光影效果，而非强对比

### GrassSea 的 CSS 架构

```
index.css (全局样式)
  |
  +-- :root (CSS 变量定义)
  |     - 色彩变量
  |     - 尺寸变量
  |     - 字体变量
  |
  +-- Reset (浏览器默认样式重置)
  |
  +-- body::before (SVG 波浪背景)
  |
  +-- .glass (磨砂玻璃工具类)
  |
  +-- Typography (h1~h5 字体层级)
  |
  +-- Scrollbar (自定义滚动条)
  |
  +-- Animations (@keyframes 动画定义)
```

这种"单文件 + CSS 变量"的方式适合中型项目——不需要引入 Sass 等预处理器，也不用 CSS Modules 或 CSS-in-JS。组件通过内联 style 属性引用变量，保持样式和作用域绑定。

### 1. CSS 变量系统 — 设计令牌

```css
:root {
  /* ---- 背景色 ---- */
  --bg-base:          #F4F6F7;  /* 页面底色，冷灰白 */
  --bg-white:         #FFFFFF;  /* 卡片/浮层底色 */

  /* ---- 强调色 ---- */
  --accent-sage:      #C1D5C0;  /* 鼠尾草绿 — 主强调色 */
  --accent-glacier:   #B5D6E0;  /* 冰川蓝 — 辅强调色 */

  /* ---- 文字色 ---- */
  --text-primary:     #222222;  /* 主要文字 */
  --text-secondary:   #666666;  /* 次要文字 */
  --text-muted:       #999999;  /* 弱化文字 */
```

**逐段解析 — 颜色设计理念**：

颜色名字体现了"自然灵感"：
- `sage` (鼠尾草) — 灰绿色调，宁静、专业、不刺眼
- `glacier` (冰川) — 灰蓝色调，冷静、理性、科技感

这两色构成 GrassSea 的"双强调色系统"，而非传统的单一品牌色。绿色用于完成/确认/植物感的状态，蓝色用于信息/链接/技术感的交互。

```css
  /* ---- 状态色 ---- */
  --status-green:     #7DBB8A;  /* 在线/完成 — 低饱和绿 */
```

状态绿的饱和度被刻意压低（正常 `#00FF00` 是 #00FF00，此处是 #7DBB8A），避免视觉攻击性。这种"低饱和 + 中明度"的配色思路是 Quiet Luxury 的核心。

```css
  /* ---- 聊天气泡 ---- */
  --bubble-left:      #E8F3F0;  /* AI 消息背景 — 淡绿 */
  --bubble-right:     #E4EEF0;  /* 用户消息背景 — 淡蓝 */
```

气泡颜色也呼应双强调色系统——AI 回复偏绿，用户输入偏蓝，形成视觉区分。

```css
  /* ---- 磨砂玻璃 ---- */
  --glass-bg:         rgba(255, 255, 255, 0.72);
  --glass-border:     rgba(255, 255, 255, 0.45);
```

磨砂玻璃的核心参数：
- `background` — 半透明白色（72% 不透明度），让背景模糊可见
- `border` — 更透明的白色边框（45%），产生"玻璃边缘"的质感

```css
  /* ---- 阴影 ---- */
  --shadow-soft:      0 1px 3px rgba(0, 0, 0, 0.04);
  --shadow-card:      0 2px 12px rgba(0, 0, 0, 0.05);
```

阴影颜色使用了**极低的透明度**（0.04 和 0.05），几乎看不到黑色，更多是"轻微浮起感"而非"有明显影子"。这也是 Quiet Luxury 的手法——阴影存在但不抢眼。

```css
  /* ---- 圆角 ---- */
  --radius-sm:        8px;   /* 小元素：标签、按钮 */
  --radius-md:        14px;  /* 中等元素：输入框、列表行 */
  --radius-lg:        22px;  /* 大元素：气泡、浮层 */
  --radius-xl:        28px;  /* 特大元素：卡片、面板 */
```

圆角是 4 级递进而非连续值，形成视觉的"节奏感"。级别之间的差值不是均匀的（8->14->22->28），渐变增加，让大元素的圆角感觉更"饱满"。

```css
  /* ---- 字体 ---- */
  --font-family: 'Inter', -apple-system, BlinkMacSystemFont,
                 "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono:   'JetBrains Mono', 'SF Mono', 'Fira Code', 'Consolas', monospace;

  /* ---- 过渡 ---- */
  --transition:  all 0.25s cubic-bezier(0.4, 0, 0.2, 1);
```

字体回退链（fallback chain）是精心设计的：
1. `Inter` — 首选西文字体（Google Fonts 加载）
2. `-apple-system` — macOS 系统字体（San Francisco）
3. `PingFang SC` — 中文首选字体（苹果平台）
4. `Microsoft YaHei` — 中文备选（Windows 平台）

过渡动画使用了 `cubic-bezier(0.4, 0, 0.2, 1)`（即 Material Design 的标准缓动），比默认的 `ease` 更有"弹性感"。

### 2. SVG 波浪背景

```css
body::before {
  content: '';
  position: fixed;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  opacity: 0.028;
  background-image: url("data:image/svg+xml,%3Csvg width='1200' ...");
  background-size: cover;
  background-position: bottom;
}
```

**逐段解析**：

1. `position: fixed; inset: 0;` — 固定在视口上，覆盖整个页面
2. `z-index: 0;` — 在所有内容下方
3. `pointer-events: none;` — **关键**！让背景不拦截鼠标事件（点击、拖拽等穿透到下方元素）
4. `opacity: 0.028;` — 极低的不透明度（2.8%），几乎不可见但又有微妙的纹理感
5. `background-image: url("data:image/svg+xml,...")` — 内联 SVG（Data URI 格式），不需要额外 HTTP 请求

内联 SVG 的内容是三条波浪曲线（使用三次贝塞尔路径），营造出海洋/波浪的意象，呼应"GrassSea"（白草沧智）的项目名称。

### 3. 磨砂玻璃工具类

```css
.glass {
  background: var(--glass-bg);
  backdrop-filter: blur(18px) saturate(130%);
  -webkit-backdrop-filter: blur(18px) saturate(130%);
  border: 1px solid var(--glass-border);
}
```

**核心技术解析**：

- `backdrop-filter: blur(18px)` — 对**元素背后的内容**进行模糊处理，而非元素本身。这是磨砂玻璃效果的核心 CSS 属性。
- `saturate(130%)` — 略微增加背后内容的色彩饱和度，让玻璃后的颜色更"鲜活"（纯模糊会让颜色变黯淡）
- `-webkit-backdrop-filter` — Safari 的厂商前缀，确保兼容性

```
+----------------------------------+
|  .glass 元素                     |
|  background: 半透明白色 (72%)    |
|  backdrop-filter: blur(18px)    |  <-- 模糊背后内容
|  border: 白色半透明              |
|                                  |
|  [玻璃内容]                      |
+----------------------------------+
     | 透过玻璃看到模糊的背景
     v
  ======================
  页面背景（模糊 + 饱和）
  ======================
```

在 TopNav、Sidebar 等组件中，只需加 `className="glass"` 就有了磨砂玻璃效果，无需重复写 CSS。

### 4. 字体层级系统

```css
h1 { font-size: 26px; font-weight: 600; letter-spacing: -0.02em; }
h2 { font-size: 20px; font-weight: 600; letter-spacing: -0.01em; }
h3 { font-size: 17px; font-weight: 500; }
h4 { font-size: 15px; font-weight: 500; }
h5 { font-size: 13px; font-weight: 600; text-transform: uppercase; letter-spacing: 0.05em; }
```

注意 h5 的特殊设计：小字号但高字重（600）、大写（`uppercase`）、宽字间距（`0.05em`）。这种组合常用于"标签"或"分组标题"，而非正文。

负字间距（`-0.02em`、`-0.01em`）让大标题更紧凑、更有"杂志感"，这是现代排版常用的微调手法。

### 5. 自定义滚动条

```css
::-webkit-scrollbar { width: 4px; height: 4px; }
::-webkit-scrollbar-track { background: transparent; }
::-webkit-scrollbar-thumb { background: rgba(0,0,0,0.10); border-radius: 10px; }
::-webkit-scrollbar-thumb:hover { background: rgba(0,0,0,0.18); }
```

将系统默认的粗滚动条（通常 12~16px）改为 4px 的超细滚动条，深灰色半透明，与整体设计风格一致。注意这些只对 WebKit 内核浏览器（Chrome/Safari/Edge）有效。

### 6. 动画系统

```css
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

@keyframes dotPulse {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.4; }
}

@keyframes fadeIn {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0); }
}
```

三个全局动画：
- `shimmer` — 流光效果（用于 ShimmerBar 底部进度条）
- `dotPulse` — 呼吸闪烁（用于在线状态指示灯）
- `fadeIn` — 向上渐入（用于消息气泡出现）

消息气泡使用 `animation: fadeIn 0.3s ease-out`，产生"消息从下方弹出"的自然感，而非突兀出现。

## 手把手实践

### 实践1: 修改全局配色方案

在浏览器中打开 GrassSea 前端，按 F12 打开开发者工具，在 Elements 面板中选中 `<html>`（或 `:root`），在 Styles 面板实时修改 CSS 变量值：

```css
/* 在开发者工具中修改（实时生效） */
--accent-sage: #FFB3BA;     /* 改为粉色系 */
--accent-glacier: #BAE1FF;  /* 改为浅蓝系 */
```

观察页面各处的颜色变化——所有引用 `--accent-sage` 的地方都变了。这就是 CSS 变量的"一处修改，全局生效"。

### 实践2: 理解磨砂玻璃

创建一个 HTML 文件测试磨砂效果：

```html
<style>
  body {
    margin: 0;
    height: 100vh;
    background: url('https://picsum.photos/1200/800') center/cover;
    display: flex;
    align-items: center;
    justify-content: center;
  }
  .glass {
    width: 400px;
    height: 300px;
    background: rgba(255,255,255,0.72);
    backdrop-filter: blur(18px) saturate(130%);
    border: 1px solid rgba(255,255,255,0.45);
    border-radius: 22px;
    padding: 30px;
  }
</style>

<div class="glass">
  <h2>磨砂玻璃效果</h2>
  <p>透过玻璃可以看到模糊的背景图片</p>
</div>
```

在浏览器中打开，调节 `blur()` 的值观察效果变化。

### 实践3: 添加一个新的全局动画

在 `index.css` 末尾添加：

```css
@keyframes slideInRight {
  from { opacity: 0; transform: translateX(20px); }
  to   { opacity: 1; transform: translateX(0); }
}
```

然后在组件中使用：

```tsx
<div style={{ animation: 'slideInRight 0.4s ease-out' }}>
  从右侧滑入的内容
</div>
```

## 常见问题与排错

### Q1: 磨砂玻璃在某些浏览器上不显示

**原因**: `backdrop-filter` 在部分旧浏览器上不支持。
**兼容性**: Chrome 76+, Safari 9+, Firefox 103+ 都支持。IE 不支持（但已不是目标浏览器）。
**降级方案**: 对于不支持的浏览器，将 `background` 调低透明度（如 0.9），看起来像是"毛玻璃不磨砂"。

### Q2: CSS 变量不生效

**检查步骤**:
1. 变量是否定义在 `:root` 中？组件中的元素能访问到吗？
2. 变量引用格式是 `var(--name)` 而不是 `var(name)` 或 `$(--name)`
3. 是否有变量名拼写错误（`--accent-sage` 不是 `--accent_sage`）

### Q3: SVG 背景不显示

**原因**:
1. `opacity: 0.028` 极低，在暗色屏幕上几乎不可见（这是设计意图）
2. `pointer-events: none` 让背景不与鼠标交互，不要在背景元素上期待交互行为

### Q4: 自定义滚动条只在 Chrome 中有效

**原因**: `::-webkit-scrollbar` 是 WebKit 私有伪元素，Firefox 不支持。
**Firefox 方案**: `scrollbar-width: thin; scrollbar-color: rgba(0,0,0,0.1) transparent;`
