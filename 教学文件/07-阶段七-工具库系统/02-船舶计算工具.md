## 概念讲解

### 四大计算工具在系统中的位置

```
                     +-----------------------+
                     |   智能体编排服务 (8002) |
                     +-----------+-----------+
                                 |

                                 |
          +----------------------+----------------------+
          |                      |                      |

  (hydrostatics)         (stability)           (resistance)

```

这四个工具都属于 `ToolCategory.COMPUTATION`，是船舶工程师最常用的核心计算工具。它们都遵循统一的 `BaseTool` 协议，可以被智能体编排服务统一调度。

### 静水力计算 (Hydrostatics)

**船舶工程背景**：静水力计算是船舶设计的"体检报告"。给定船型参数（L, B, T, Cb），计算排水量、浮心位置、稳心高度等最基本的水动力参数。

**简化公式（教学中使用）**：

```
排水量 Δ = L × B × T × Cb × ρ           (ρ=1.025 t/m³ 海水密度)
浮心纵向位置 LCB = -0.05 × L × (1 - Cb)  (以船舯为原点)
稳心高度 KM = KB + BM = T/2 + B²/(12T) × (1 + Cb/2)
湿面积 S = L × (2T + B) × √Cb
```

### 稳性分析 (Stability)

**船舶工程背景**：稳性决定船在海浪中会不会翻。GM（初稳性高度）是最重要的稳性指标。IMO（国际海事组织）要求 GM >= 0.15m。

**横摇周期公式**：

```
Tr = 2 × C × B / √GM

其中: C = 0.38 (经验系数), B = 型宽, GM = 初稳性高度
```

### 阻力计算 (Resistance)

**船舶工程背景**：阻力计算用于估算船舶所需的主机功率。Holtrop 法是业界广泛使用的回归方法。

**关键计算链**：

```
速度 V(m/s) = V_kn × 0.5144

雷诺数 Re = V × L / ν        (ν=1.19×10⁻⁶ 运动粘性系数)

摩擦阻力系数 Cf = 0.075 / (log₁₀(Re) - 2)²  (ITTC 1957 公式)

摩擦阻力 Rf = 0.5 × ρ × S × V² × Cf

总阻力 Rt = Rf × 1.4          (1.4 是形状因子估计值)

有效功率 Pe = Rt × V
```

### 船型改造 (Hull Transform)

**船舶工程背景**：在船舶初步设计中，常以"母型船"为参考，通过尺度缩放得到"子船"的参数估计值。

```
缩放比 λ = L_target / L_parent

新参数: B_new = B_parent × λ
        D_new = D_parent × λ
        T_new = T_parent × λ
```

## 项目代码精讲

### 1. 静水力计算工具

**文件位置**: `tools/computation/hydrostatics.py`

```python
HYDROSTATICS_MANIFEST = ToolManifest(
    tool_id="hydrostatics",
    name="静水力计算",
    description="排水量、浮心、稳心、邦戎曲线等静水力参数计算",
    category=ToolCategory.COMPUTATION,
    input_schema={
        "type": "object",
        "properties": {
            "L":  {"type": "number"},  # 船长
            "B":  {"type": "number"},  # 型宽
            "T":  {"type": "number"},  # 吃水
            "Cb": {"type": "number"},  # 方形系数
        }
    },
    output_schema={
        "type": "object",
        "properties": {
            "displacement":   {"type": "number"},  # 排水量
            "LCB":           {"type": "number"},  # 浮心纵向位置
            "KM":            {"type": "number"},  # 稳心高度
        }
    },
)
```

**逐段解析**：

`input_schema` 定义了4个输入参数，都是 `number` 类型。JSON Schema 的 `properties` 描述了一个"对象"有哪些字段。前端可以根据这个 schema 自动生成输入表单。

```python
class HydrostaticsTool(BaseTool):
    def __init__(self):
        super().__init__(HYDROSTATICS_MANIFEST)
```

`super().__init__(HYDROSTATICS_MANIFEST)` 调用父类 `BaseTool` 的构造函数，将 manifest 传入。这是标准的 Python 继承写法。

```python
async def execute(self, params: dict, context: dict) -> dict:
    L, B, T, Cb = params.get("L", 100), params.get("B", 15), \
                   params.get("T", 5), params.get("Cb", 0.75)
```

`params.get("L", 100)` 的意思是：从 params 字典中取 key 为 `"L"` 的值，如果不存在，使用默认值 `100`。这是一种"防御性编程"——即使调用方少传了参数，工具也不会崩溃。

```python
    disp = L * B * T * Cb * 1.025       # 排水量（吨）
    lcb = -0.05 * L * (1 - Cb)          # 浮心纵向位置
    km = B * B / (12 * T) * (1 + Cb / 2) # 稳心高度

    return {
        "status": "completed",
        "displacement_t": round(disp, 1),
        "LCB_m": round(lcb, 2),
        "LCB_from_midship": round(lcb, 2),
        "KM_m": round(km, 2),
        "KB_m": round(T * 0.5, 2),
        "BM_m": round(km - T * 0.5, 2),
        "block_coefficient": Cb,
        "wetted_surface_m2": round(L * (2 * T + B) * (Cb ** 0.5), 1),
    }
```

`round(value, 2)` 保留2位小数，`round(value, 1)` 保留1位。在工程计算中，有效数字位数很重要——排水量通常精确到吨，浮心位置精确到厘米（0.01m）。

### 2. 稳性分析工具

**文件位置**: `tools/computation/stability.py`

```python
import numpy as np
```

注意这里 import 了 `numpy`，但只用到了 `np.sqrt()`。如果项目不允许引入 numpy，可以用 `math.sqrt()` 替代，效果完全相同。

```python
async def execute(self, params: dict, context: dict) -> dict:
    B = params.get("B", 15)
    GM = params.get("GM", 2.0)
    C, Tr = 0.38, 2 * 0.38 * B / np.sqrt(max(GM, 0.01))
```

`max(GM, 0.01)` 是重要的安全保护——如果 GM 为负数或零，`np.sqrt()` 会报错，使用 `max()` 保证根号下始终为正数。

**稳性判据的设计**：

```python
    criteria = [
        {
            "name": "IMO 初稳性",
            "requirement": "GM >= 0.15m",
            "value": f"{GM:.2f}m",
            "pass": GM >= 0.15
        },
        {
            "name": "横摇周期",
            "requirement": "建议 <= 25s",
            "value": f"{Tr:.1f}s",
            "pass": Tr <= 25
        },
    ]
```

这是一个结构化的"判定结果"列表。每个判据包含四个字段：
- `name` — 判据名称
- `requirement` — 规范要求
- `value` — 计算值（已格式化）
- `pass` — 是否通过 （`True/False`）

前端可以直接用这块数据渲染一个判定表。这种"让工具返回结构化判断结果"的设计模式，比简单的"通过/不通过"更有价值。

### 3. 阻力计算工具

**文件位置**: `tools/computation/resistance.py`

```python
async def execute(self, params: dict, context: dict) -> dict:
    L, B, T, V = params.get("L", 100), params.get("B", 15), \
                   params.get("T", 5), params.get("V_kn", 14)

    Vs = V * 0.5144                                  # 节 -> 米/秒
    Rn, Cf = Vs * L / 1.19e-6, \
             0.075 / (np.log10(Vs * L / 1.19e-6) - 2) ** 2
```

**公式来源详解**：

- `0.5144` — 1 节 = 0.5144 m/s（航海速度单位转换）
- `1.19e-6` — 海水的运动粘性系数 ν（15度时）
- `np.log10(...)` — 计算以 10 为底的雷诺数对数
- `Cf = 0.075 / (log10(Re) - 2)^2` — ITTC 1957 摩擦阻力系数公式

然后计算摩擦阻力和总阻力：

```python
    S = L * (2 * T + B) * (0.75 ** 0.5)     # 湿表面积估算
    Rf = 0.5 * 1025 * S * Vs ** 2 * Cf / 1000  # 摩擦阻力 (kN)
    Rt = Rf * 1.4                              # 总阻力 (kN) = 摩擦×形状因子
```

`1025` 是海水密度（kg/m³），`/1000` 将 N 转为 kN。

```python
    return {
        "status": "completed",
        "method": "Holtrop",
        "speed_kn": V,
        "Reynolds_number": f"{Rn:.2e}",     # 科学记数法
        "friction_coefficient": f"{Cf:.6f}",  # 6位小数
        ...
        "effective_power_kW": round(Rt * Vs, 1),
    }
```

`f"{Rn:.2e}"` 使用科学记数法显示雷诺数（如 `1.18e+09`），这在渲染大数值时非常直观。

```python

    parent_L, target_L = params.get("parent_L", 100), params.get("target_L", 120)
    ratio = target_L / parent_L

    return {
        ...
```

注意最后的 `warnings` 字段——当缩放比超过 1.2 时，工具会自动给出工程建议。工具不仅返回计算结果，还会返回"工程判断提示"，这是 GrassSea "AI + 专业领域" 结合的一个体现。

## 常见问题与排错

### Q1: 稳性工具中 GM 为负数时出错

**错误信息**: `math domain error` 如果直接使用 `math.sqrt(GM)`
**解决**: 代码中已使用 `max(GM, 0.01)` 保护，确保不会出错。

### Q2: 计算结果的精度问题

**现象**: 和手算结果有偏差
**原因**: 教学工具中的公式是简化版（如湿表面积估算），实际工程中需要更精确的公式。这是刻意为之——教学阶段用简化模型，生产环境用专业模型。

### Q3: 为什么排水量单位是"吨"而不是"千克"？

船舶工程中重量/排水量通常以"吨"（1000kg）为单位。`1.025` 是海水密度（t/m³），这样计算出的 `L×B×T×Cb` 是"排水体积"（m³），乘密度后就是"吨"。

### Q4: 雷诺数 1.18e+09 是什么意思？

`1.18e+09` = `1.18 × 10^9` = 11.8亿。雷诺数通常非常大（百万到十亿级别），科学记数法是标准写法。
