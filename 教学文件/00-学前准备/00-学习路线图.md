## 1. 全局学习路径

GrassSea 是一个微服务架构的 AI 平台，涉及的技术栈比较广。我们把学习过程拆成 **12 个阶段 + 1 个前置准备**，像搭积木一样逐层构建。

### 阶段全景图

```
你在这里 ──▶  00 学前准备 (Python 进阶)
  │              ├── 异步编程 (async/await)
  │              ├── 数据验证 (Pydantic)
  │              ├── 数据库ORM (SQLAlchemy)
  │              └── Web框架 (FastAPI 进阶)
  │
  ▼           01 项目初始化
               │  理解项目骨架是怎么搭起来的
               │  学会管理配置、日志、Docker 环境
               │
  ┌────────────┴──────────────────────┐
  │  02 数据库    03 模型网关    04 RAG  │  ← 三个基础服务可以并排理解
  │  数据怎么存    AI怎么调用    知识怎么查 │
  └────────────┬──────────────────────┘
               │
               ▼  05 智能体编排  ← 核心：把多个 AI 组织起来干活
               │
               ▼  06 业务智能体  ← 给 AI 赋予专业能力
               │
               ▼  07 工具库      ← AI 的手和脚
               │
               ▼  08 API 网关    ← 对外统一入口
               │
               ▼  09 前端开发    ← 用户看到的界面
               │
               ▼  10 安全认证    ← 保护系统
               │
               ▼  11 可观测性    ← 监控系统运行
               │
               ▼  12 测试部署    ← 让系统稳定上线
```

### 核心思想：分层架构

GrassSea 采用 **5 层架构**，从上到下每层调用下一层的能力：

```
┌────────────────────────────┐
│  前端 (React)              │  ← 用户直接操作
├────────────────────────────┤
│  API 网关 (Chat Service)   │  ← 统一入口，认证+路由
├────────────────────────────┤
│  智能体编排 (Agent Service) │  ← 意图识别+任务调度+状态管理
├────────────────────────────┤
│  业务智能体 (Agents)        │  ← 专业 AI 角色
├────────────────────────────┤
│  能力中台 (RAG+Model+Tools) │  ← AI 的基础能力
├────────────────────────────┤
│  数据底座 (PG+Mongo+Redis)  │  ← 所有数据的家
└────────────────────────────┘
```

**理解这个分层**是读懂整个项目的关键。教学文件也是按这个思路从下往上讲的。

## 3. "看-学-做-查"四步学习法

每学一个教学文件，按以下四步走：

### 第一步：看（10 分钟）
先快速浏览全文，看标题、看图表、看代码段，**不求完全理解**，建立整体印象。

### 第二步：学（30-60 分钟）
仔细阅读每个章节：
1. **概念讲解**：理解"为什么需要这个技术"
2. **代码精讲**：打开项目源文件对照阅读，看注释理解每行代码的作用
3. **视频学习**：如果文字理解困难，看推荐的视频

### 第三步：做（60-120 分钟）
这是**最重要的一步**：
1. 跟着「手把手实践」部分，自己新建一个测试文件
2. 把代码敲一遍（不要复制粘贴！）
3. 故意改错一些地方，看报什么错（加深理解）
4. 完成末尾的练习任务

### 第四步：查（遇到问题时）
1. 先看本文件的「常见问题与排错」部分
2. 搜索错误信息（复制到 Google/Bing）
3. 把错误和代码发给 AI 助手帮忙分析
4. 实在解决不了，记录下来，继续往后学（后面可能会自然明白）
