## 4. 缺陷列表

### 4.0 历史 S1（已修复，审计留痕）

| ID | 标题 | 状态 |

| S1-H1 | `@asynccontextmanager` 被顶掉 → `TypeError: object _AsyncGeneratorContextManager can't be used in 'await' expression` → uvicorn `sys.exit(3)` 拖垮 4 服务 | **已修复 `e9e2691f`** |

### S2-1 专业计算接受 NaN / 负值 / 1e12 并返回 `completed`

- **位置**：`tools/computation/hydrostatics.py`（参数未做 `math.isfinite` / 正值校验）
- **影响**：可能把 `nan`/`inf`/负排水量当作有效结果交给模型并写进 Word 报告
- **复现**：
  ```python
  reg = await build_tool_registry()
  await reg.execute_tool("hydrostatics", {"length": float("nan"), "breadth": 1, "draft": 1}, {})
  # → {'status': 'completed', ...}
  ```
- **修复**：工具入口统一做 `isfinite` + 正值 + 上限校验，越界返回 `status="error"`
- **回归**：`nan / inf / -1 / 0 / 1e12 / 缺失` 六组，断言 `status=="error"`

### S2-2 pytest 未安装，CI 检查无法执行

- **证据**：`F:\GrassSea\.venv\Scripts\python.exe: No module named pytest`
- **影响**：README「开发」小节的 `uv run pytest` / `uv run ruff check .` 在当前环境不可执行；无自动化回归
- **修复**：`uv sync --extra dev`，并在 README 明确前置条件

### S2-3 前端依赖无锁文件

- **影响**：`npm install` 结果不可复现
- **修复**：提交 `frontend/package-lock.json`

### S3-1 前导斜杠路径被静默重写而非拒绝

- **位置**：`tools/doc/_common.py::resolve_output`（`rel.lstrip("/")`）
- **证据**：`resolve_output("/etc/passwd")` → `F:\GrassSea\data\outputs\etc\passwd`
- **影响**：**未越界**（仍在 outputs 内），但属静默行为差异
- **修复**：开头加 `if Path(rel_path).is_absolute(): raise DocPathError(...)`

### S3-2 select 型配置不做枚举校验

- **证据**：`coerce_setting(s, "PDF_CONVERTER", "__evil__")` → 原样接受
- **影响**：非法值进入运行时，直到调用转换器才报「未知的转换引擎」
- **修复**：按 `CONFIG_SCHEMA.options` 校验枚举

### S3-3 `hydrostatics({})` 全用默认值且返回 `completed`

- **影响**：模型零参数也能得到「完整」结果
- **修复**：输出带 `used_defaults: true` 与字段清单
